# n1clude's NixOS Configuration Flake

A configuration for the Linux system of my dreams :3

## Installation

1. Have a NixOS installation ready.
2. Clone the repo.
3. Install:
  ```bash
  nixos-rebuild switch --flake /path/to/repo#niclude-laptop # Laptop configuration
  ```
